# 💰 Personal Expense Tracker (Java Project)

## 📌 Project Overview

The Personal Expense Tracker is a Java-based application designed to help users manage and track their monthly expenses efficiently.  
It allows users to record expenses, view spending details, and maintain better financial control.

This project demonstrates core Java programming concepts and basic application development skills.

---

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)

---

## 🚀 Features

- Add new expenses
- View all recorded expenses
- Calculate total expenses
- Manage monthly spending records
- Simple and user-friendly structure

---

## ▶️ How to Run the Project

1. Clone or download this repository
2. Extract the project files (if zipped)
3. Open the project in your IDE (IntelliJ / Eclipse / VS Code)
4. Run the `Main.java` file


## 📚 Concepts Practiced

- Java classes and objects
- Methods and loops
- Conditional statements
- File handling
- Basic application logic design
